# ES 678 Course Project: Subject-Level ADHD Classification from EEG

This repository contains code and result files for an individual ES 678 course project at IIT Gandhinagar. The study compares spectral-only EEG features with a multi-domain feature representation for participant-level ADHD/control classification.

## Research question

Does a multi-domain EEG feature representation improve subject-level ADHD classification compared with spectral features alone, and which classical machine-learning model performs most consistently on previously unseen participants?

## Dataset and access

- Original dataset: *EEG data for ADHD/Control Children*, IEEE DataPort, DOI: [10.21227/rzfh-zn36](https://doi.org/10.21227/rzfh-zn36).
- The analysis notebook accessed a CSV mirror: [Kaggle dataset `danizo/eeg-dataset-for-adhd`](https://www.kaggle.com/datasets/danizo/eeg-dataset-for-adhd).
- The dataset contains 121 children (61 ADHD and 60 controls), 19 EEG channels, and a sampling frequency of 128 Hz.
- Eight channels were used: F3, F4, Fz, P3, P4, Pz, O1, and O2.
- The supplied experiment generated 5,621 epochs using 2-second windows (256 samples) and a 3-second step (384 samples), leaving a 1-second gap between windows.
- The final feature table has 199 multi-domain features per epoch. The spectral subset contains 40 features (theta, alpha, beta power, theta/beta ratio, and theta/alpha ratio across eight channels).

Do not redistribute the raw EEG dataset unless its terms explicitly allow redistribution. Obtain it directly from the original source or the Kaggle mirror. Store `adhdata.csv` locally at `data/adhdata.csv`; the `data/` directory is ignored by Git.

### Kaggle access

You may download the CSV through the Kaggle website, or configure the Kaggle CLI locally. Never commit `kaggle.json` or API tokens. For Colab, use a private secret or a secure runtime upload; do not publish credential-bearing notebook outputs.

## Methods

The comparison uses a prior-probability Dummy Classifier baseline and three candidate models:

- Logistic Regression
- Random Forest
- RBF-kernel Support Vector Machine (SVM)

Each model is assessed with spectral and multi-domain features. Five-fold `GroupKFold` keeps all epochs from a participant in one outer fold. Epoch probabilities are averaged to produce one prediction per participant. Imputation, feature selection, and scaling are fitted inside the training pipeline; SVM probability calibration uses three participant-grouped inner folds. The model settings are fixed for this reported experiment; no global hyperparameter search is claimed.

## Reproduce feature extraction and evaluation

1. Obtain the dataset and place `adhdata.csv` at `data/adhdata.csv` (the raw-data folder is ignored by Git).
2. Extract the features:

```bash
python src/extract_features.py --input data/adhdata.csv --output data/features_199.csv
```

3. Run the comparison:

```bash
python src/evaluate.py --features data/features_199.csv --output results
```

The scripts default to 2-second windows and a 3-second step, matching the uploaded notebook version used for the reported metrics. If changing these settings, regenerate all results and update the paper accordingly.

The code scripts are a reproducibility companion. Before claiming exact reproduction, verify that their outputs agree with the actual executed Colab notebook and the committed metrics. Add that executed notebook to `notebooks/` before submission.

## Reported results

The supplied participant-level out-of-fold results show:

- Spectral features: best candidate balanced accuracy 64.3% (Random Forest).
- Multi-domain features: candidate balanced accuracy approximately 77.6–77.7% and accuracy 77.7% for all three learned classifiers.
- Multi-domain Random Forest: highest ROC-AUC (86.3%) and specificity (75.0%).
- Multi-domain SVM: highest ADHD sensitivity (88.5%).

See [`results/metrics.csv`](results/metrics.csv) and [`results/metrics.json`](results/metrics.json) for the full metrics. The Dummy classifier's pooled ROC-AUC is not treated as a meaningful ranking measure because fold-specific prior scores are not on a common learned ranking scale. The Dummy baseline is interpreted mainly through its 50% balanced accuracy and majority-class behavior.

## Limitations

The independent sample comprises 121 participants, not 5,621 independent cases. Participants contribute unequal numbers of epochs; GroupKFold prevents participant overlap but does not guarantee class-stratified folds. There is no external test cohort. The findings are dataset-specific and do not establish clinical diagnostic validity.
